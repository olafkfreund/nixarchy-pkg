# Intent: the small ones

## Problem

Six defects found on razer that lose nothing, each small enough that a task
of its own would be ceremony. Grouped here so they are tracked, not
forgotten.

1. **The Options tab says it searches nixpkgs.** Its placeholder is
   "search nixpkgs…" and its empty state "type to search nixpkgs". It
   searches options. (`Menu.qml:263-264` picks the placeholder on
   `indexTab`, which is true for both Selection and Options.)
2. **A flag given without its value prints nothing.** `nixarchy-pkg search
   git --limit` (or `--kind`) exits 1 with empty output: `shift 2` fails
   under `set -e`. The header promises every subcommand prints one object
   and exits 0. The panel never sends this; a terminal user or a script
   can.
3. **A search cannot start with `-`.** `search -git` is read as an unknown
   flag. There is no `--` to end the flags.
4. **unfree is shown twice.** `hello-unfree  unfree  Example package …
   [unfree]`: once as the row's flag, once inside the summary text the
   index carries.
5. **The README's install produces a plugin that fails validation.** Home
   Manager installs `~/.config/omarchy/plugins/nixarchy.pkg` as a symlink
   into the store. `omarchy plugin validate` refuses it ("symlinks are not
   allowed inside a plugin folder"), and by the README's own note
   `rescanPlugins` won't reload it. The README's development section warns
   about symlinks; its install section produces one.
6. **Tabs look clickable and are not.** Clicking a tab does nothing. The
   panel is keyboard-first by design, but nothing on screen says the mouse
   won't work here.

## Proposed outcome

Each item either fixed or explicitly declined, with the reason written
down.

## Affected users and systems

- `Menu.qml`, `Card.qml` (copy, flag display, maybe tab clicks).
- `bin/nixarchy-pkg` `cmd_search`.
- `README.md`, and possibly nixarchy's Home Manager plugin module (item 5
  may be nixarchy's to fix, not this repo's).

## Constraints

- No behaviour change beyond each item. This is not the place to rework
  the search or the install.
- Item 5 must not break the existing install path for anyone already using
  it.

## Open questions

1. **Item 5 belongs where?** If the fix is "Home Manager should copy, not
   link", that is `programs.nixarchy.plugins` in nixarchy, and this repo
   only documents it. Should it be filed there instead?
2. **Item 6: make tabs clickable, or leave them keyboard-only?** Clicking
   is a few lines; leaving it is consistent with "everything from the home
   row".
3. **Item 4: strip `[unfree]` from the summary, or not draw the flag?** The
   flag is the structured one; the summary text comes from the index
   builder in nixarchy.
