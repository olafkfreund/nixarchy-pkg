# Plan: stream the apply log, as plain text, with an outcome you can see

## The approved decisions, in full

**Ask, don't guess.** `cmd_apply` runs `nixarchy-apply --yes --no-preview`
with stdin from `/dev/null`. It deletes the `command -v nixarchy-preview`
answer-building (`bin/nixarchy-pkg:1111-1116`) and the "Not switching."
check (`:1123-1133`). That check misses the phrase 50/50 times under the
adapter's own `set -euo pipefail` once output passes ~64 KB, and then
reports `applied`. With `--yes` there is nothing to detect. A nixarchy
without the flags fails with its usage line through the normal failure
path; no version probe.

**Stream through awk, not `sed -u`.** The filter is
`awk '{ gsub(/\033\[[0-9;?]*[A-Za-z]/, ""); gsub(/\033[()][A-Za-z0-9]/, ""); sub(/.*\r/, ""); print; fflush() }'`.
It strips CSI and charset escapes, keeps the last redraw of a CR progress
line, flushes every line, and newline-terminates an unterminated last
line. `sed -u … '$a\'` was measured holding each line until the next
(1007 ms vs 7 ms). `NO_COLOR=1` is set as a request; the strip is the
guarantee. Stripping lives in the adapter so a terminal user gets the
same text.

**Right exit code.** The pipeline runs with `set +e +o pipefail`,
`PIPESTATUS` is copied at once, and then `set -e -o pipefail` is restored.
`[0]` is nixarchy-apply's status, `[1]` is awk's. An awk failure is
reported as its own error.

**An unmistakable final record.** The last line is
`{"nixarchyPkgApply":{"ok":…,"exit":…,"message":…}}`. The QML ends the
apply only on an object with that key; today any line with a boolean
`ok` and a numeric `exit` ends it.

**The panel shows start, stream and end.** `a` opens the log with
`starting rebuild…  ESC stops watching; the build carries on`. The final
record's message is appended as the last log line (`— applied —` /
`— failed: … —`), and the log stays until ESC. A process exit with no
record clears `applying` after one `Qt.callLater` tick and appends
`— the apply ended without a result; see above —`. ESC still only
detaches.

**Not changed:** QML plain-text rendering; `nixarchy-apply`; the shell
restart risk (noted, out of scope).

**Spec item 7 is moot:** the "minimal PATH" at `tests/adapter.sh:157`
exists only for the preview-count tests this deletes, so it goes with
them. No test here needs a minimal PATH.

2. **`cmd_apply`** (`:1071-1138`): replace the body with

       need nixarchy-apply
       local statuses rc frc
       set +e +o pipefail
       NO_COLOR=1 NH_ELEVATION_STRATEGY="${NH_ELEVATION_STRATEGY:-pkexec}" \
         nixarchy-apply --yes --no-preview </dev/null 2>&1 |
         awk '{ gsub(/\033\[[0-9;?]*[A-Za-z]/, ""); gsub(/\033[()][A-Za-z0-9]/, "")
                sub(/.*\r/, ""); print; fflush() }'
       statuses=("${PIPESTATUS[@]}")
       set -e -o pipefail
       rc=${statuses[0]}; frc=${statuses[1]}

   then one `jq -nc` producing `{nixarchyPkgApply:{ok:(rc==0 and frc==0),
   exit:rc, message}}`. `message` is `applied`, `nixarchy-apply exited N`,
   or `the log filter failed (exit F); nixarchy-apply exited N`. The

   says why awk and not `sed -u`.
