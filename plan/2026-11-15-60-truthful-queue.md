and the files each step names, nothing else. **Coders never stage or
commit.** The coordinator commits after each step, as `feat(adapter): …
(#60)`, `feat(panel): … (#60)`, `test: … (#60)` or `docs: … (#60)`.

After every step, run:

## Decisions (from the approved spec)

**What apply does** (`nixarchy-apply`). Mirror it; do not reinvent it.

- **Locations.**
  - `flake=${NIXARCHY_FLAKE:-/etc/nixos}`; `host=$(uname -n)`.
  - `base=$flake/hosts/$host` if that directory exists, else `$flake`
    (`flake_base()` already computes this).
  - `base_rel` is `hosts/$host` or empty. Build paths with `${base_rel:+$base_rel/}`
    so an empty value never produces `//`.
- **Copying.**
  - The parts, in order, are apps, services, advanced and flatsnap. Each is
    copied from `$CONFIG_DIR/<p>.nix` to `$base/nixarchy/<p>.nix` when the
    source exists and differs.
  - apply regenerates `$base/nixarchy-apps.nix` to import
    `./nixarchy/<p>.nix` for each part whose source exists, in that order.
    Its exact text is:

    ```
    # Generated by nixarchy-apply. Do not edit -- your files
    # are ~/.config/nixarchy/{apps,services,advanced,flatsnap}.nix and
    # this is regenerated from them on every apply.
    {
      imports = [ ./nixarchy/apps.nix ./nixarchy/services.nix ];
    }
    ```

    The `imports` list has one ` ./nixarchy/<p>.nix` per part present.
  - A destination is never deleted.
  - Drafts are `$CONFIG_DIR/packages/*.nix`, copied to
    `$base/nixarchy/packages/`. A draft is retained when its source is
    deleted.
- **Records.** A record lives at
  `rec=$STATE_DIR/applied/$(printf '%s' "$dst" | sha256sum | cut -c1-16)`
  (`STATE_DIR` already ends in `/nixarchy`) and holds the full
  `sha256sum <"$dst"` output.
  "Edited in the flake" means `[ -f "$rec" ] && ! sha256sum <"$dst" | cmp -s - "$rec"`.
- **Conflicts.**
  - A part whose source exists, differs from the destination, and whose
    destination was edited in the flake is `overwrite`: apply keeps a copy,
    then overwrites.
  - A draft in the same situation is `blocks`: apply exits 1 before copying.
- **Pins.** `--expect-sha256 <p>=<hex|"">`, parts only. An empty hash means
  "must be absent". Drafts cannot be pinned. A mismatch prints
  `is not what you checked`.

**Reads.**
- `pending` and `check` never take #59's lock. `$STATE_DIR/pkg-recovery/open`
  existing means a write is in progress or was interrupted.
- **Private copies.** Each command copies with `cp -L` into a 0700
  directory made under `$STATE_DIR`, never `/tmp`:

  | command | directory | `on_exit` variable |
  |---|---|---|
  | `pending` | `pkg-read.XXXXXX` | `READDIR` |
  | `check` | `pkg-check.XXXXXX` | `CHECKDIR` |
  | `apply` | `pkg-apply.XXXXXX` | `APPLYDIR` |

  Only the global `on_exit` removes them; no command installs its own
  `EXIT` trap. `begin_write` sweeps only `pkg-work.*`.

**New `nix` calls** (in `check`) use `"${NIX[@]}"`, which is
`nix --extra-experimental-features 'nix-command flakes'`, and close fds 8 and
9. Existing `nix` calls elsewhere in the adapter are **not** changed: their
test stubs read `$1 $2`. New stubs must find the subcommand after those two
flag words (`$3 $4`). No `--impure` and no `--option` anywhere.

Manual checks run on **razer** only, never p620.

## Steps

### 1. Shared plumbing (`bin/nixarchy-pkg`)

- **Top-level variables.** After `WORK=""`, add `READDIR=""`, `CHECKDIR=""`,
  `APPLYDIR=""`, `CHILD=""` and `CHECKING=false`.
- **`on_exit()`.** Change it to this order:
  1. `local rc=$?`, then `trap '' TERM INT HUP` (as today).
  2. If `CHILD` is set:
     `kill -TERM -- "-$CHILD" 2>/dev/null || :`, then
     `wait "$CHILD" 2>/dev/null || :`, then `CHILD=""`. The child dies
     **before** its directory is removed.
  3. The existing `GUARDED` and `WRITING` answer branches, unchanged.
  4. A new branch, after them:
     `elif $CHECKING; then jq -nc --arg e "the check was interrupted (exit $rc)" '{ok:false, error:$e}'; rc=0`.
     `cmd_check` sets `CHECKING=false` just before it prints its own answer,
     so this fires only when it did not get there.
  5. Clean `WORK`, `READDIR`, `CHECKDIR` and `APPLYDIR`, each the way `WORK`
     is cleaned today (`chmod -R u+w`, then `rm -rf`, errors ignored).
  6. `exit "$rc"`.
- **Helpers**, after `flake_base()`:

  ```bash
  NIX=(nix --extra-experimental-features 'nix-command flakes')

  # base_rel -- "" or "hosts/<host>", matching flake_base.
  base_rel() {
    local flake=${NIXARCHY_FLAKE:-/etc/nixos}
    if [ -d "$flake/hosts/$(uname -n)" ]; then printf 'hosts/%s' "$(uname -n)"; fi
  }

  # imported PART BASE -- apply's generated import file imports it now.
  imported() { [ -f "$2/nixarchy-apps.nix" ] && grep -qF "./nixarchy/$1.nix" "$2/nixarchy-apps.nix"; }

  # record_for DST -- apply's record file for a flake destination.
  record_for() { printf '%s/applied/%s' "$STATE_DIR" "$(printf '%s' "$1" | sha256sum | cut -c1-16)"; }

  # edited_in_flake DST -- apply's own test.
  edited_in_flake() { local r; r=$(record_for "$1"); [ -f "$r" ] && ! sha256sum <"$1" | cmp -s - "$r"; }

  # private_dir VAR PREFIX -- 0700 dir in STATE_DIR, cleaned by on_exit. Never inside $(...).
  private_dir() {
    mkdir -p "$STATE_DIR" || die "cannot create $STATE_DIR"
    local d; d=$(mktemp -d -p "$STATE_DIR" "$2.XXXXXX") || die "cannot create a working directory in $STATE_DIR"
    printf -v "$1" '%s' "$d"
  }

  # snapshot_selection DIR -- cp -L every existing part to DIR/<p>.nix and draft to DIR/packages/.
  snapshot_selection() {
    local p f
    mkdir -p "$1/packages" || die "cannot create $1"
    for p in apps services advanced flatsnap; do
      f=$CONFIG_DIR/$p.nix
      [ -e "$f" ] || continue
      [ -r "$f" ] || die "cannot read $f"
      cp -L "$f" "$1/$p.nix" || die "could not copy $f"
    done
    for f in "$CONFIG_DIR"/packages/*.nix; do
      [ -e "$f" ] || continue
      [ -r "$f" ] || die "cannot read $f"
      cp -L "$f" "$1/packages/" || die "could not copy $f"
    done
  }

  # fingerprint DIR -- one sha256 over every .nix in DIR, names included.
  fingerprint() {
    ( cd "$1" && find . -type f -name '*.nix' -print0 | sort -z | xargs -0r sha256sum ) |
      sha256sum | cut -d' ' -f1
  }

  # pins_json DIR -- {"apps":"<hex>|\"\"", ...} for the four parts in a snapshot.
  pins_json() {
    local p args=()
    for p in apps services advanced flatsnap; do
      if [ -f "$1/$p.nix" ]; then args+=(--arg "$p" "$(sha256sum <"$1/$p.nix" | cut -d' ' -f1)")
      else args+=(--arg "$p" ""); fi
    done
    jq -nc "${args[@]}" '{apps:$apps, services:$services, advanced:$advanced, flatsnap:$flatsnap}'
  }
  ```

→ **Verify:** the three commands, plus each helper called by hand with a
throwaway `XDG_STATE_HOME` and `XDG_CONFIG_HOME`. `pins_json` of an empty
directory gives four `""`.

**Traps.**
- `fingerprint` must give the same answer in `pending` and `check`. Both
  use `snapshot_selection`, so the layouts match.
- The source-shape checks in `tests/adapter.sh` (around "no diff, comm or
  cmp at the head of a pipeline" and "nothing is piped into head") forbid
  `diff … |` / `cmp … |` at the start of a pipeline, and `| head`. Nothing
  added here may use those shapes.

### 2. `pending` rewrite (`bin/nixarchy-pkg`)

Replace `pending_changes()` and `cmd_pending()`, and keep `marked()`. Take
`base=$(flake_base)` as `cmd_pending` does today.

**Read.**
1. `private_dir READDIR pkg-read`.
2. Set `writing=false`, or `true` if `$TXN/open` exists.
3. `snapshot_selection "$READDIR"`.
4. If `$TXN/open` exists now, set `writing=true`.

**Diff helper**, no pipes, statuses checked:

```bash
# twoway A B OUT -- diff A B into OUT; a missing side is /dev/null; dies on diff error (status > 1).
twoway() {
  local a=$1 b=$2 rc=0
  [ -e "$a" ] || a=/dev/null
  [ -e "$b" ] || b=/dev/null
  diff "${@:4}" "$a" "$b" >"$3" || rc=$?
  [ "$rc" -le 1 ] || die "could not compare $1 and $2"
}
```

**Per part** `p`, with `src=$READDIR/$p.nix` (the private copy) and
`dst=$base/nixarchy/$p.nix`:

- An existing `dst` that is not readable is `die`.
- `cmp -s src dst` with status 2 is `die`; never treat it as "differs".

| condition | status |
|---|---|
| src exists, `! imported "$p" "$base"` | `new` |
| src exists, dst missing | `new` |
| src exists, `cmp -s` says they differ | `modified` |
| src missing, `imported "$p" "$base"` | `dropped` |
| otherwise | unchanged: **no entry, and no marked rows** |

For an entry:

- **`unmarked`**:
  - `grep -v '#@' "$dst" >"$READDIR/$p.dst.u" || :`, and the same for
    `src` into `$p.src.u` (`/dev/null` when missing);
  - then `twoway "$READDIR/$p.dst.u" "$READDIR/$p.src.u" "$READDIR/$p.ud"`;
  - then `unmarked=$(grep -c '^[<>]' "$READDIR/$p.ud" || :)`.
- **`hunk`**: `twoway "$dst" "$src" "$READDIR/$p.hunk" -u`, then the first
  200 lines with `sed -n '1,200p'`. `sed`, not `head`.
- **`conflict`**: `overwrite` when src exists, dst exists, they differ, and
  `edited_in_flake "$dst"`; otherwise `null`.

**Marked rows** (only for parts that have an entry):

1. Write `marked "$dst"` and `marked "$src"` to files: `marked` already
   tolerates a missing file.
2. Run `twoway` on them, as `pending_changes` diffs today.
3. Turn `>` lines into `+` records and `<` lines into `-` records:
   `{file:"<p>", sign, line, marker}`. Extract `marker` with the existing
   `capture("#@(?<t>[a-z-]*)[ \t]+(?<n>[^ \t]+)")`, as `type:name`.
4. Pair them in `jq`. `group_by([.file, .marker])`; within each group,
   index the `-` and the `+` records separately, then:
   - `i < min(#minus, #plus)`: one `modified` row, with the `+` side's
     `line`;
   - extra `+` rows: `on` when the type is empty, otherwise `added`;
   - extra `-` rows: `off` when the type is empty, otherwise `removed`.
   - The old `group_by(.marker)` is gone.
5. **`lineNo`**, for `on`, `added` and `modified`, is the line number of the
   **k-th** occurrence of that exact `line` text in `src`, counting k within
   its group. Compute it in `awk` over `src`: strip leading whitespace, then
   compare. `off` and `removed` get `null`.

**Drafts.** For each `$READDIR/packages/<n>.nix`, with
`dst=$base/nixarchy/packages/<n>.nix`:

- status is `new` (dst missing) or `modified` (`cmp` differs; status 2 is
  `die`);
- `unmarked` and `hunk` as for parts;
- `conflict: "blocks"` when they differ and `edited_in_flake "$dst"`;
- no marked rows.

**Answer** (one `jq -n`):

- `ok`, `neverApplied`, `base`, `writing`.
- `count`: `changes | length`.
- `changes[]`: `{marker, file, line, change, lineNo}`. `file` is `"apps"`
  and so on, as today.
- `files[]`: `{file, label, path, status, unmarked, hunk, conflict, explained}`.
  - **`file`**: `"apps"` for a part, or `"packages/foo.nix"` for a draft.
  - **`label`**: the display name, `"apps.nix"` or `"packages/foo.nix"`.
  - **`path`**: the live source path when the live source exists, otherwise
    `null`.
  - **`explained`**: `status == "modified" and unmarked == 0` and at least
    one `changes[]` row has this `file`.
- `total`: `(changes|length) + (files | map(select(.explained|not)) | length)`.
- `fingerprint`: `fingerprint "$READDIR"`.
- `pins`: `pins_json "$READDIR"`.
- `sources`: `{apps, services, advanced, flatsnap}`, each the live
  `$CONFIG_DIR/<p>.nix` path when it exists, otherwise `null`. The panel
  opens these.
- `unpinned`: `{drafts: [every existing packages/*.nix label, changed or not], flake: true}`.

**Tests.** Add a new section to `tests/adapter.sh`,
`echo "the queue apply will copy (#60)"`, outside `HAVE_CATALOGUE`.

Setup:
- Use throwaway `XDG_CONFIG_HOME`, `XDG_STATE_HOME` and `NIXARCHY_FLAKE`.
- Build the "applied" state by hand: `$flake/nixarchy/*.nix`, a
  `$flake/nixarchy-apps.nix` in the format above, and records written as
  `sha256sum <dst >rec`, at the path `record_for` computes.
- The flake directory needs no `hosts/<host>`.

Cases:
1. a `flatsnap.nix` edit;
2. a new draft;
3. an unmarked continuation-line edit under an unchanged marked line;
4. a whitespace-only edit: `total ≥ 1`, `explained: false`;
5. a commented catalogue-line edit;
6. the same marker in two files, and twice in one file: separate rows, and
   the two in one file get different `lineNo`;
7. a changed marked value: `modified`, with the right `lineNo`;
8. a dropped part: `dropped`;
9. after regenerating `nixarchy-apps.nix` without that part: `files == []`
   **and** `changes == []`;
10. re-creating the part identical to the leftover destination: `new`;
11. a record mismatch with `src` present gives `overwrite`; with `src`
    deleted, no conflict;
12. a draft mismatch: `blocks`;
13. `pins` equal `sha256sum` of each source, and `""` when absent;
14. `unpinned.drafts` lists an unchanged draft;
15. a draft edit changes `fingerprint` and leaves `pins` the same;
16. `writing: true` while `$XDG_STATE_HOME/nixarchy/pkg-recovery/open`
    exists;
17. an unreadable destination: `ok:false`;
18. a never-applied machine: every part is `new`.

In every case, check:
- `count == (changes|length)`;
- `total == 0` iff `files == []`;
- no `pkg-read.*` is left;
- the test's `TMPDIR` is empty.

→ **Verify:** the three commands, and the source-shape checks still pass.

**Traps.**
- `count`'s meaning is unchanged. Its numbers may rise only through the
  merge fix.
- Never compare a destination against the live source. Always use the
  private copy.

### 3. `cmd_check` (`bin/nixarchy-pkg`)

Wire `check)` into `main`, and add `check [--dry-run]` to the usage string
and the header comment. `--dry-run` is the only flag; anything else is
`die`. Every outcome below prints exactly one JSON answer.

1. **Start.**
   - `flake=${NIXARCHY_FLAKE:-/etc/nixos}`. If `[ -f "$flake/flake.nix" ]`
     is false: `die "no flake at $flake"`.
   - `mkdir -p "$STATE_DIR"`, then `exec 8>"$STATE_DIR/pkg-check.lock"`.
   - `flock -n 8 || die "a check is already running"`.
   - Set `CHECKING=true`.
   - Remove stale `"$STATE_DIR"/pkg-check.*/` directories: run
     `chmod -R u+w` on them first, never touch the `.lock`, and skip the
     current `CHECKDIR` once it exists.
2. **Answer helper.** `answer` takes the current variables, sets
   `CHECKING=false`, prints the one `jq -nc` object, and `exit 0`s. Every
   later verdict goes through it.
   - **Always present**: `ok:true`, `host`, `verdict`, `fingerprint`,
     `pins`, `unpinned`, `blocked`, `note`.
   - **When set**: `reason`, `drvPath`, `summary`, `error`, `at`,
     `dryRun`, `dryRunError`.
3. **Writes.** If `$TXN/open` exists: `verdict:"unknown"`,
   `reason:"a write is in progress or was interrupted -- try again, or run recover"`.
4. **Snapshot.**
   - `private_dir CHECKDIR pkg-check`, then
     `snapshot_selection "$CHECKDIR/snap"`.
   - `F1=$(fingerprint "$CHECKDIR/snap")`, and
     `pins=$(pins_json "$CHECKDIR/snap")`.
   - `unpinned` and `blocked` are computed as `pending` computes them, from
     the snapshot.
5. **Guards.** Each of these gives `verdict:"unknown"` with the quoted
   `reason`:
   - `base=$(flake_base)` and `br=$(base_rel)`. If any of `$base`,
     `$base/nixarchy` or `$base/nixarchy/packages` is a symlink (`[ -L ]`):
     "the flake's nixarchy directory is a symlink -- the check will not
     write through it".
   - `[ -e "$flake/.git" ]` and
     `git -C "$flake" grep -lE 'self\.(rev|shortRev|dirtyRev|dirtyShortRev|lastModified|lastModifiedDate)\b' -- '*.nix'`
     matches: "this flake reads its own git revision; a copy would evaluate
     differently". A `git` error here (exit > 1) gives "git failed:
     <stderr>".
   - `[ -f "$flake/flake.lock" ]` and
     `jq -e '[.nodes[]? | .locked? // empty | select(.type=="path" and ((.path // "") | startswith("/") | not))] | length > 0'`
     is true: "this flake has a relative path input; a copy would not
     resolve it".
   - `[ -e "$flake/.git" ]` and `git -C "$flake" ls-files -s` has a line
     starting `160000`: "this flake has git submodules; the check does not
     copy them".
6. **Materialise.**
   - `copy=$CHECKDIR/flake` and `cb=$copy${br:+/$br}`.
     `mkdir -p "$copy"`.
   - If `[ -e "$flake/.git" ]`:

     ```bash
     git -C "$flake" ls-files -z | while IFS= read -r -d '' f; do
       if [ -e "$flake/$f" ] || [ -L "$flake/$f" ]; then printf '%s\0' "$f"; fi
     done | tar -C "$flake" --null --no-recursion -T - -cf - | tar -C "$copy" -xf -
     ```

     Then, if `$base/nixarchy` exists, `mkdir -p "$cb/nixarchy"` and
     `cp -a "$base/nixarchy/." "$cb/nixarchy/"`. It cannot be a symlink:
     step 5 refused that.
   - Otherwise: `cp -a "$flake/." "$copy/"`.
   - A failure anywhere here gives `verdict:"unknown"`,
     `reason:"could not copy the flake: <first stderr line>"`. Capture
     stderr into `$CHECKDIR/cp.err`, using `|| rc=$?`.
   - If `$cb`, `$cb/nixarchy` or `$cb/nixarchy/packages` is a symlink in the
     copy (tracked symlinks), stop with the step 5 symlink reason.
7. **Overlay.**
   - `mkdir -p "$cb/nixarchy/packages"`.
   - For each `snap/<p>.nix` and each `snap/packages/*`: `rm -f` the target,
     then `cp`.
   - `rm -f "$cb/nixarchy-apps.nix"`, then write the generated text above,
     listing the parts present in `snap/` in order.
8. **Root and host.**
   - `root` and the flake check: run
     `"${NIX[@]}" flake metadata --json "path:$copy" >"$CHECKDIR/meta" 2>"$CHECKDIR/err" 9>&- 8>&-`
     with `|| rc=$?`. A non-zero exit gives `verdict:"fails"`, with the
     error rewritten as below, using `root=""`.
     Otherwise `root=$(jq -r .path "$CHECKDIR/meta")`.
   - The host: run
     `"${NIX[@]}" eval --json "path:$copy#nixosConfigurations" --apply "c: builtins.hasAttr \"$host\" c"`
     with the same redirections.
     - It prints `false`: `die "this flake has no nixosConfigurations.$host"`.
     - It fails and its stderr contains `does not provide attribute`:
       `die "this flake has no nixosConfigurations"`.
     - Any other failure: `verdict:"fails"`, with the rewritten error.
9. **Evaluate.** Do **not** use `$(...)`:

   ```bash
   setsid timeout 900 "${NIX[@]}" eval --raw \
     "path:$copy#nixosConfigurations.\"$host\".config.system.build.toplevel.drvPath" \
     >"$CHECKDIR/out" 2>"$CHECKDIR/err" 9>&- 8>&- &
   CHILD=$!
   rc=0; wait "$CHILD" || rc=$?; CHILD=""
   ```

   | `rc` | result |
   |---|---|
   | 124 | `verdict:"unknown"`, reason "timed out after 15 minutes" |
   | other non-zero | `verdict:"fails"` |
   | 0 | `verdict:"evaluates"`, `drvPath=$(cat "$CHECKDIR/out")` |

10. **`--dry-run`**, only after `evaluates`. Run
    `"${NIX[@]}" build --dry-run "$drvPath^*"` the same way: `setsid
    timeout 900 … &`, `CHILD`, `wait`, stderr to `$CHECKDIR/dry`.
    - Parse it with one `awk`:
      - a line matching `will be built` gives the count from
        `these ([0-9]+) derivations`, or 1 when the line says
        `this derivation`;
      - `will be fetched` gives the count from `these ([0-9]+) paths`, or 1
        for `this path`;
      - the size comes from `\(([0-9.]+) (B|KiB|MiB|GiB) download`,
        converted to MiB with two decimals.
    - A non-zero exit, or non-empty output with no recognised line, gives
      `dryRun:null` and `dryRunError` (the first stderr line).
    - Empty output gives `{build:0, fetch:0, downloadMiB:0}`.
11. **Superseded.** Run `snapshot_selection "$CHECKDIR/snap2"` and compute
    `F2`. If `F2 != F1`, or `$TXN/open` exists, the verdict becomes
    `superseded`.
12. **IFD note.** Run
    `"${NIX[@]}" config show allow-import-from-derivation 9>&- 8>&- 2>/dev/null || :`.
    - It always says: "Checked evaluation only, not a build or a switch.
      This is evidence, not a guarantee: apply evaluates again for real."
    - When that config prints `true`, add: " With import-from-derivation
      on, evaluating may have built some inputs."

**Error rewrite** (for `fails`). Read `$CHECKDIR/err` and replace literal
strings, never a regex, in this order. Skip any rule whose prefix is empty:
1. `"$root/${br:+$br/}nixarchy/packages/"` and
   `"$copy/${br:+$br/}nixarchy/packages/"` become `"$CONFIG_DIR/packages/"`.
   A draft that exists only in the flake (no source) maps to
   `"$base/nixarchy/packages/"` instead.
2. `"$root/${br:+$br/}nixarchy/"` and `"$copy/${br:+$br/}nixarchy/"` become
   `"$CONFIG_DIR/"`.
3. `"$root/"` and `"$copy/"` become `"$flake/"`.

Other store paths are left untouched.

- **`error`**: the last 200 lines, via `tail -n 200` on the file. Not a
  pipe from `head`.
- **`summary`**: the text of the last line matching
  `^[[:space:]]*error:[[:space:]]*[^[:space:]]`, with the whitespace and
  `error:` removed. If there is none, take the first non-empty line after
  the last line matching `^[[:space:]]*error:[[:space:]]*$`, trimmed.
- **`at`**:
  - the last `$CONFIG_DIR/<x>.nix:<n>:` (including `packages/<n>.nix`)
    gives `{file:"<x>.nix", line:n}`;
  - otherwise, the last `In '$CONFIG_DIR/<x>.nix'` gives

### 6. `PkgModel.qml`

**Properties.**
- `pendingData: null`, `queueError: ""`.
- `queued` starts at `-1`.
- `checkResult: null`, `checkRunning: false`, `detailText: ""`.
- `armingState: ""` (one of `""`, `"reading"` or `"armed"`).
- `armedKind: ""`, `armedPins: ({})`, `armedFingerprint: ""`.
- `_pendingWant: 0`, `_pendingRun: 0`, `_armWant: 0`, `_pendingAgain: false`.
- `_checkStopping: false`, `_afterCheck: ""` (`""`, `"here"` or
  `"terminal"`).
- `signal terminalStarted()`.
- `armedApply` stays, so existing bindings keep working. It is set to
  `armedKind` when `armed`, and to `""` otherwise.

**Tabs.** `tabs` gains `"Queue"`, and
`readonly property bool queueTab: tab === 6`.

**Reads.**
- `refreshPending()` increments `_pendingWant`.
  - If `_pending.running`: set `_pendingAgain = true` and return.
  - Otherwise: set `_pendingRun = _pendingWant` and start it.
- `_pending.onExited`: if `_pendingAgain`, set `_pendingAgain = false`, then
  `_pendingRun = _pendingWant`, and start it again.
- `_pending.onStreamFinished` parses the answer:
  - On `ok:true`: set `pendingData`,
    `queued = (typeof data.total === "number") ? data.total : -1`,
    `neverApplied`, and `queueError = ""`.
  - On `ok:false` or a parse error: `queued = -1`, and
    `queueError = data.error || "could not read the queue"`.
  - Then **invalidate**:
    - If `checkResult` exists, its `fingerprint` differs from
      `data.fingerprint`, and both are set: `checkResult = null`.
    - If `armingState === "reading"` **and** `_pendingRun >= _armWant`, this
      is the fresh read; freeze it:
      - `ok:false`: `disarm()`, with `message` set to the error.
      - `writing`: `disarm()`, with `message = "a write is in progress -- try again in a moment"`.
      - Otherwise:
        - `armedPins` is `checkResult.pins` when
          `checkResult.verdict === "evaluates"` and
          `checkResult.fingerprint === data.fingerprint`, else `data.pins`;
        - `armedFingerprint = data.fingerprint`;
        - `armingState = "armed"`, `armedApply = armedKind`;
        - `message` is `(armedKind === "terminal" ? "SHIFT+A again" : "a again") + " to rebuild: " + data.total + (data.total === 1 ? " change" : " changes") + (nConflicts ? " -- " + nConflicts + " edited in the flake" : "") + " -- any other key cancels"`;
        - restart `_applyArmTimer`.
    - If `armingState === "armed"` and `data.fingerprint !== armedFingerprint`:
      `disarm()`, with `message = "the queue changed -- review it again"`.

**`armApply(kind)`** keeps its signature and returns true only on the
confirming press.
- When `armingState === "armed"` and `kind === armedKind`: stop the timer,
  set `armingState = ""`, and return `true`. **Keep `armedPins`.** `apply()`
  and `applyInTerminal()` read them, then call `disarm()`.
- When `armingState === "reading"`: `message = "still reading the queue"`,
  return `false`.
- When `queued === -1 && queueError`: `message = "queue unknown -- press r"`,
  return `false`.
- Otherwise: `disarm()`, `armingState = "reading"`, `armedKind = kind`,
  `message = "reading the queue…"`, `refreshPending()`,
  `_armWant = _pendingWant`, return `false`.

**`disarm()`** also clears `armingState`, `armedKind`, `armedPins`,
`armedFingerprint` and `armedApply`.

**`apply()`.**
- `args = [script, "apply"]`, plus `"--pin", p + "=" + armedPins[p]` for
  each key, then `disarm()`.
- If `checkRunning`: set `_afterCheck = "here"`, store `args`, and
  `cancelCheck()`. Start it in `_check.onExited`.
- Otherwise start it now.

**`applyInTerminal()`.**
- The command is
  `["omarchy-launch-floating-terminal-with-presentation", "nixarchy-apply"]`
  plus `"--expect-sha256=" + p + "=" + armedPins[p]` for each key, then
  `disarm()`.
- The same deferral as `apply()`, with `"terminal"`.
- When `_applyTerm.running = true` actually happens, emit
  `terminalStarted()`.
- It still refuses while `applying` or `busy`, as today, with its message.

**Check.**
- `_check` is a `Process`. `check(dry)` refuses while `checkRunning` or
  `applying`. Otherwise it sets the command to `[script, "check"]` (plus
  `"--dry-run"`), `checkResult = null`, `checkRunning = true`, and starts.
- `onStreamFinished`, unless `_checkStopping`:
  - unparseable output, or `ok:false`, gives
    `checkResult = {verdict: "unknown", reason: data.error || "the check did not answer"}`;
  - otherwise `checkResult = data`, with
    `checkResult.verdict = "superseded"` when `data.fingerprint !== pendingData.fingerprint`.
- `onExited`:
  - `checkRunning = false`;
  - if `_checkStopping`, set `_checkStopping = false` and
    `checkResult = null`, dropping the stopped run;
  - if `_afterCheck`, start the deferred apply and set `_afterCheck = ""`.
- `cancelCheck()`: if `checkRunning`, set `_checkStopping = true` and
  `_check.running = false`.

**Queue rows.** `rows()` on the Queue tab returns objects
`{kind, text, path, detail}`. The model builds every text; the view only
draws `text`.

1. **`check`**, when `checkRunning || checkResult`:
   - running: "checking… (about a minute) -- ESC cancels";
   - `evaluates`: "evaluates ✓", plus " -- B to build, F to fetch (M MiB)"
     when `dryRun`, " -- dry run: <dryRunError>" when `dryRunError`, and
     " -- apply will stop: <label> was edited in the flake" per `blocked`
     entry;
   - `fails`: "fails: <summary> (<at.file>:<at.line>, as checked)". Leave
     the line out when it is null, and the brackets out when `at` is null;
   - `superseded`: "superseded -- press c again";
   - `unknown`: "could not check: <reason>".

   `detail` is `checkResult.error || checkResult.reason || ""`; `path` is
   `null`.
2. **`conflict`**, one per `files[]` entry with a `conflict`:
   - `overwrite`: "<label> was edited in the flake -- apply will keep a
     copy and overwrite it";
   - `blocks`: "<label> was edited in the flake -- apply will stop".

   `detail` is the `hunk`.
3. **`writing`**: "a write is in progress or was interrupted -- the queue
   may be out of date".
4. **`change`**, for each `changes[]` entry:
   - the text is "<name> <verb> (<file>.nix:<lineNo>)", or "(<file>.nix)"
     when `lineNo` is null;
   - `name` is the marker after the first `:`;
   - `verb` is one of "on", "off", "added", "removed" or "changed"
     (`modified`);
   - `path` is `pendingData.sources[file]` for `on`, `added` and
     `modified`, and `null` for `off` and `removed`;
   - `detail` is `line`.
5. **`file`**, for each `files[]` entry with `explained:false`:
   - "<label>: N lines changed" (modified, `unmarked > 0`);
   - "<label>: new";
   - "<label>: no longer imported" (dropped);
   - "<label>: whitespace or comments changed" (modified, `unmarked == 0`).

   `path` is the entry's `path`, null for `dropped`. `detail` is `hunk`.
6. **`note`**: "not pinned: the flake's own files", plus ", and drafts: " +
   the comma-joined `unpinned.drafts` when there are any.

**Tests** in `tests/qml/tst_pkgmodel.qml`:
- **Cleanup.** Extend `cleanup()` to reset every new property, plus

- **Stub limits.** The stub `Process`'s `deliver(text)` does not emit

Cases:

10. A check answer with a stale fingerprint is shown as `superseded`.
11. `cancelCheck()` followed by `finish()` drops the result.

→ **Verify:** `nix flake check`.

**Traps.**
- Use `typeof` for numbers. `data.total || 0` hides an unknown queue.
