## Decisions (from the approved spec)

- **No automatic reindexing** here. The panel says how old the index is.
- **A new `index` object beside `indexStale`** in `state`, `search` and
  `reindex`:
  `{"status": "fresh"|"stale"|"missing", "builtAt": <unix seconds>|null, "changed": [names]|null}`.
- **`indexStale` keeps its exact meaning**: `status != "fresh"`, where
  `status` is computed with today's test byte for byte (`[ -s "$INDEX" ]`,
  then the stamp file's content against the seven `searched` values joined
  by newlines). Its corner cases are kept, not fixed: an index with no
  stamp and no `nixarchy-search` on `PATH` compares equal and reads fresh.
- **`builtAt`** is `stat -c %Y` of `index.tsv`, only when the status is not
  `missing` and `stat` succeeds; else `null`. It is when the index was
  built; the panel says "built … ago", never "stale for".
- **`changed`** is a list only when: status is `stale`; `nixarchy-search`
  is on `PATH`; the stamp, read with `mapfile -t` (keeps an empty line),
  has exactly 7 lines; and both the stamp's lines and the current values
  are recognised by suffix (table below). Otherwise `null`. Names in input
  order, no duplicates. An empty list is reported as `null`.

  | i | Input | Must match (glob) | Name |
  | --- | --- | --- | --- |
  | 0 | `nixpkgs` | `*-source` | nixpkgs |
  | 1 | `walk` | `*-pkg-index.nix` | index builder |
  | 2 | `optionsjson` | `*/options.json`, or empty | options |
  | 3 | `appindex` | `*-nixarchy-app-index.tsv` | app list |
  | 4 | `apptable` | `*-nixarchy-app-attrs.tsv` | app list |
  | 5 | `flatpakrows` | `*-nixarchy-flatpak-rows.tsv` | flatpaks |
  | 6 | `pkgnewrow` | `*-nixarchy-pkg-new-row.tsv` | new-package row |

- **No nixpkgs revision**: the stamp's nixpkgs line is
  `/nix/store/<hash>-<hash>-source`, which has none.
- **A failed reindex answers `error`** (the documented contract: "`ok` on
  every object, and `error` when `ok` is false"), plus `detail`, an array of
  strings. Success answers `{ok:true, indexStale:false, index, message:"index rebuilt"}`.
- **Noise** removed from `detail` (after trimming each line): lines starting
  `Building the search index.`; starting `indexing nixpkgs (this takes`;
  starting `no option index: documentation.nixos.enable is off`; equal to
  `system, so there is no options.json to read.`; equal to
  `inappropriate ioctl for device`; starting `evaluation warning:`.
  `detail` keeps at most the last 8 lines.
- **`error`** is one line:
  `the search index is still <stale|missing>: <reason> -- see <cache>/index-errors.log`,
  where `<reason>` is the last `detail` line not starting
  `indexing nixpkgs failed;`, or `nixarchy-search gave no reason`.
- Measured (p620, throwaway `XDG_CACHE_HOME`): `nixarchy-search --reindex
  </dev/null` takes 44.5 s, peaks at 5.0 GB, **exits 0**; stderr is the two
  progress lines and `inappropriate ioctl for device`. `index-errors.log`:
  598 of 600 lines are `evaluation warning:`. `state` takes 0.12 s.
- **Panel text** (`indexLine(now)`):
  - no `index` (older adapter): `index stale — r to rebuild`;
  - `missing`: `no search index — r to build it`;
  - otherwise the parts joined with ` — `: `index built <age>` (or
    `index stale` when `builtAt` is null), then `<names> changed` when
    `changed` is a non-empty list, then `r to rebuild`.
  - `<age>`: `max(0, now/1000 - builtAt)` seconds; under 60 →
    `just now`; under 60 minutes → `N minute(s) ago`; under 48 hours →
    `N hour(s) ago`; else `N day(s) ago`; singular for 1.
  - `<names>`: one → `a`; two → `a and b`; more → `a and N more`.
  - Example: `index built 14 days ago — nixpkgs and 4 more changed — r to rebuild`.

### 1. `index_facts` (codex)

```bash
# The seven inputs nixarchy-search keys the index on, in its stamp_key
# order; what each looks like; and what the panel calls it.
INDEX_INPUTS=(nixpkgs walk optionsjson appindex apptable flatpakrows pkgnewrow)
INDEX_GLOBS=('*-source' '*-pkg-index.nix' '*/options.json' '*-nixarchy-app-index.tsv'
             '*-nixarchy-app-attrs.tsv' '*-nixarchy-flatpak-rows.tsv' '*-nixarchy-pkg-new-row.tsv')
INDEX_NAMES=(nixpkgs 'index builder' options 'app list' 'app list' flatpaks 'new-package row')

# index_recognised V0..V6 -- every value has its input's shape (options may be empty).
index_recognised() {
  local i=0 v
  for v in "$@"; do
    if ! { [ "$i" = 2 ] && [ -z "$v" ]; }; then
      # shellcheck disable=SC2053  # the right side is a glob on purpose
      [[ $v == ${INDEX_GLOBS[i]} ]] || return 1
    fi
    i=$((i + 1))
  done
  [ "$i" = 7 ]
}

# index_facts -- {status, builtAt, changed} as one JSON object.
# status keeps index_stale's old test byte for byte, so indexStale is
# exactly `.status != "fresh"`.
index_facts() {
  local status built key i cur=() st=() names=()
  if [ ! -s "$INDEX" ]; then
    jq -nc '{status: "missing", builtAt: null, changed: null}'
    return 0
  fi
  for i in "${INDEX_INPUTS[@]}"; do cur+=("$(searched "$i")"); done
  key=$(printf '%s\n' "${cur[@]}")
  if [ "$(cat "$STAMP" 2>/dev/null)" != "$key" ]; then status=stale; else status=fresh; fi
  built=$(stat -c %Y "$INDEX" 2>/dev/null) || built=""
  if [ "$status" = stale ] && command -v nixarchy-search >/dev/null 2>&1 && [ -r "$STAMP" ]; then
    mapfile -t st <"$STAMP"
    if [ "${#st[@]}" -eq 7 ] && index_recognised "${st[@]}" && index_recognised "${cur[@]}"; then
      for i in 0 1 2 3 4 5 6; do
        [ "${st[i]}" = "${cur[i]}" ] || names+=("${INDEX_NAMES[i]}")
      done
    fi
  fi
  jq -nc --arg status "$status" --arg built "$built" \
    --args '{status: $status,
             builtAt: (if $built == "" then null else ($built | tonumber) end),
             changed: ($ARGS.positional
                       | reduce .[] as $n ([]; if any(.[]; . == $n) then . else . + [$n] end)
                       | if length == 0 then null else . end)}' \
    ${names[@]+"${names[@]}"}
}
```

```bash
cmd_reindex() {
  need nixarchy-search
  # nixarchy-search builds the index, then opens its picker; with no
  # terminal the picker fails ("inappropriate ioctl for device") and the
  # script still exits 0. So its status says nothing, and the stamp is the
  # judge. stderr is kept for the reason when the index is still stale.
  local err facts
  err=$(NIXARCHY_IN_PICKER=1 nixarchy-search --reindex </dev/null 2>&1 >/dev/null 9>&- 8>&-) || :
  facts=$(index_facts)
  if jq -e '.status == "fresh"' <<<"$facts" >/dev/null; then
    jq -nc --argjson index "$facts" \
      '{ok: true, indexStale: false, index: $index, message: "index rebuilt"}'
    return 0
  fi
  jq -nc --arg err "$err" --argjson index "$facts" \
    --arg log "$CACHE_DIR/index-errors.log" '
    ($err | split("\n")
          | map(sub("^\\s+"; "") | sub("\\s+$"; ""))
          | map(select(length > 0
              and (startswith("Building the search index.") | not)
              and (startswith("indexing nixpkgs (this takes") | not)
              and (startswith("no option index: documentation.nixos.enable is off") | not)
              and (. != "system, so there is no options.json to read.")
              and (. != "inappropriate ioctl for device")
              and (startswith("evaluation warning:") | not)))
          | .[-8:]) as $d
    | ([$d[] | select(startswith("indexing nixpkgs failed;") | not)] | last) as $why
    | {ok: false, indexStale: true, index: $index, detail: $d,
       error: ("the search index is still \($index.status): "
               + ($why // "nixarchy-search gave no reason")
               + " -- see " + $log)}'
}
```

  ```js
  function indexLine(now) {
    var ix = index
    if (!ix) return "index stale \u2014 r to rebuild"
    if (ix.status === "missing") return "no search index \u2014 r to build it"
    var parts = [typeof ix.builtAt === "number"
                 ? "index built " + _ago(now / 1000 - ix.builtAt)
                 : "index stale"]
    if (ix.changed && ix.changed.length > 0) parts.push(_names(ix.changed) + " changed")
    parts.push("r to rebuild")
    return parts.join(" \u2014 ")
  }
  function _ago(s) {
    s = Math.max(0, s)
    if (s < 60) return "just now"
    var m = Math.floor(s / 60)
    if (m < 60) return m + (m === 1 ? " minute" : " minutes") + " ago"
    var h = Math.floor(m / 60)
    if (h < 48) return h + (h === 1 ? " hour" : " hours") + " ago"
    var d = Math.floor(h / 24)
    return d + (d === 1 ? " day" : " days") + " ago"
  }
  function _names(n) {
    if (n.length === 1) return n[0]
    if (n.length === 2) return n[0] + " and " + n[1]
    return n[0] + " and " + (n.length - 1) + " more"
  }
  ```

## Companion issues

**A. nixarchy-search: a reindex-only mode that never opens the picker**

> `nixarchy-search --reindex` builds the index and then opens `fzf`.
> Called without a terminal (as `nixarchy-pkg reindex` does), the picker
> fails with "inappropriate ioctl for device" and the script exits 0, so
> the exit status says nothing about whether indexing worked. A mode that
> builds the index, prints nothing on success, exits non-zero when indexing
> fails, and never reaches the picker would let callers trust the status
> and drop the noise filtering. nixarchy-pkg keeps its stamp check either
> way.

**B. Rebuild the search index after a new system generation, in the background**

> The index is keyed on its inputs and goes stale silently after any
> rebuild that moves nixpkgs; on one machine it was 14 days old with six of
> seven inputs changed. An optional user unit that runs the reindex-only
> mode (A) when `/run/current-system` changes, at low priority and never
> during `nixarchy-apply`, would keep it fresh. It costs about 45 s and
> 5 GB of memory per run (measured), so it should be opt-in or deferred
> until the session is idle.
