# Plan: the small ones

Item 6 (clickable tabs) depends on #27's `focusList()`; implement after
#27 merges. The rest are independent.

## The approved decisions, in full

1. **Options copy.** Placeholder `search NixOS options…`, empty state
   `type to search NixOS options`. Selection keeps "nixpkgs".
2. **A flag without its value** dies with `--limit needs a value` /
   `--kind needs a value`: one object, exit 0.
3. **`--` ends flags** in `cmd_search`, and the panel's `runSearch`
   sends `--` before the query, so `-foo` is searchable from both.
4. **Double flags.** In the adapter's jq, remove ` [unfree]` from
   `summary` only when the row's flags include `unfree`, and ` [broken]`
   only when they include `broken`. Old indexes without flags keep their
   only warning.
5. **Install.** The README tells people to validate the build output,
   not the installed symlink, and says why. The development note keeps
   what is established (validate refuses symlinks) and states that
   rescan/reload through a symlink is untested, recommending
   `omarchy-restart-shell`. An issue is filed on nixarchy proposing the
   validator follow a top-level store symlink or the module copy. No
   migration here.
6. **Clickable tabs.** Each tab label gets a `MouseArea` calling
   `model.setTab(index)`. Focus follows #27 through `onTabChanged`.
7. **README contradictions.** `:81-82` "never `/etc/nixos`" becomes
   "selection files only, except the Flakes tab, which appends one marked
   line to the system flake and locks it (see Flakes)". `:57` "needs no
   build" becomes "usually needs no build".

## Steps

1. **Options copy.** `Menu.qml:263-264`: the placeholder becomes
   `pkg.flakeTab ? … : pkg.tab === 3 ? "search NixOS options…" :
   pkg.indexTab ? "search nixpkgs…" : "filter…"`.
   `Card.qml:237`: a `root.model.tab === 3 ? "type to search NixOS
   options"` branch ahead of the `indexTab` one.
   -> verify by panel check 1.

2. **Flag values.** `bin/nixarchy-pkg:194-195`: `--kind)  [ $# -ge 2 ]
   || die "--kind needs a value"; kind=$2; shift 2 ;;`, same for
   `--limit`. Add `--) shift; query=${1-}; break ;;` ahead of `-*)`, so
   the argument after `--` is the query. Update the
   usage string to `search [--kind K] [--limit N] [--] <query>`.
   -> verify by tests 1–2.

3. **Panel sends `--`.** `PkgModel.qml:268-273`: the command becomes
   `[script, "search", "--kind", …, "--limit", "60", "--", query]`.
   -> verify by panel check 2.

4. **Double flags.** `bin/nixarchy-pkg:236-250`: compute `flags` first
   (as `$f`), then `summary: ((.[2] // "") | if ($f | index("unfree"))
   then gsub(" \\[unfree\\]"; "") else . end | if ($f | index("broken"))
   then gsub(" \\[broken\\]"; "") else . end)`. Only package rows; option
   rows are untouched.
   -> verify by test 3.

5. **Clickable tabs.** `Card.qml:50` (the tab `Item`): add
   `MouseArea { anchors.fill: parent; onClicked: if (root.model)
   root.model.setTab(parent.index) }`. No `cursorShape`, matching the
   rows' `MouseArea` (`Card.qml:129`), which sets none.
   -> verify by panel check 3.

6. **README.**
   - `:57`: "usually needs no build (a flake using import-from-derivation
     can make it build; the adapter gives up after 120 s)".
   - `:81-82`: the sentence from decision 7.
   - Install section: after `omarchy plugin enable`, a note to validate
     `"$(nix build --print-out-paths .#default)"`, because the Home
     Manager install is a store symlink that `plugin validate` refuses by
     design.
   - `:183-185`: "rescanning a plugin reached through a symlink has not
     been verified to reload changed QML; `omarchy-restart-shell` does".
   -> verify by reading, and by `nix flake check` (the manifest and
   colour checks don't cover the README, so reading is the check).

7. **Upstream issue** on `olafkfreund/nixarchy`: "`programs.nixarchy.plugins`
   installs a plugin as a store symlink that `omarchy plugin validate`
   refuses", with the error text, the two options (validator follows a
   top-level store symlink; the module copies) and a link to #30. Put its
   URL in the README install note.
   -> verify by the issue existing and the README linking it.

8. **`tests/adapter.sh`** `search` section. Tests 1–2 need no index;
   test 3 uses a stub. So they sit **before** the existing
   index-dependent `if`:
   1. `search git --limit` and `search git --kind` → `.ok == false`,
      exit 0 (`check` on the exit status and the object).
   2. With a temp `XDG_CACHE_HOME` holding a stub `nixarchy/index.tsv`
      that has a row named `-dash`: `search -- -dash` →
      `.rows[0].name == "-dash"`.
   3. The same stub with `pkg⇥foo⇥Foo thing [unfree]⇥unfree⇥` and
      `pkg⇥bar⇥Bar thing [unfree]⇥⇥` → `foo`'s summary is `Foo thing`,
      `bar`'s keeps `[unfree]`.
   -> verify by `bash tests/adapter.sh` → `all passed`.
